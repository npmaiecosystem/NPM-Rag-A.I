Privacy Controls

💬 Using Chat Mode

1

Open the App & select "Chat"

Click the App page from the navigation and make sure the "Chat" tab is active.

2

Upload files (optional)

Attach PDFs, images, or MP4 videos. You can also paste a YouTube URL for automatic transcription.

3

Give your Knowledge Base a name

Type a short name like my-docs. This namespaces your uploads.

4

Type your question and hit Send

The AI will answer using both your uploaded context and its general knowledge, with session memory.

🛠 Building a RAG Knowledge Base

1

Switch to "Build RAG" tab

This mode ingests your documents into a persistent vector database — not just a chat session.

2

Choose Public or Private

Public bases can be queried by anyone who knows the DB name. Private bases require your secret username.

3

Upload your documents

Supports PDF, PNG/JPG, MP4 video, and YouTube links. Multiple files are accepted at once.

4

Name your Knowledge Base and send

The question field is hidden in Build mode. Just name your DB and hit Send to start ingestion.

⚡ API Quick Reference

The backend exposes three endpoints:

# 1 — Multimodal Chat POST /ask query string — user question DB_PATH string — knowledge base name file file[] — PDFs, images, videos (optional) link string — YouTube URL (optional) # 2 — Query Existing RAG POST /use DB_PATH string query string DB_Privacy "publi"|"privat" secret_key string — required if private # 3 — Ingest / Build RAG POST /develop DB_PATH string DB_Privacy "publi"|"privat" file file[] link string — YouTube URL (optional)
